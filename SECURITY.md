# Security Policy

## Supported Versions

Currently, Vella is in rapid development. Security updates are applied only to the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |
| < v0.1  | :x:                |

## Reporting a Vulnerability

Security is a core pillar of Vella (e.g., our FHE and Zero-Knowledge features). If you discover a vulnerability, **do not open a public issue.** 

Please email the core team directly at `security@vella.dev` (placeholder for real email). 

We will acknowledge your report within 48 hours, and you will be credited in our advisory once the patch is released.
