# 🎨 Vella: The Frontend Developer's Guide (React, Vue, Angular)

If you are a frontend developer coming from Firebase, Supabase, or PocketBase, Vella is designed to feel instantly familiar while offering drastically more power via its AI Gateway and Real-Time Engine.

This guide provides comprehensive examples for integrating Vella with **React**, **Vue 3**, and **Angular**.

---

## 1. Zero-Config TypeScript Generation

You never have to manually write TypeScript interfaces for your database again. When you compile Vella in development mode, it automatically reads your Rust schema and generates a `vella-types.ts` file.

```typescript
// Auto-generated by Vella
export interface User {
    id: number;
    email: string;
    created_at: string;
}

export interface DeliveryZone {
    id: number;
    // GIS Spatial Types are automatically mapped to TS types!
    boundary: Record<string, any>; // GeoJSON Polygon
    center_point: [number, number]; // [Longitude, Latitude]
}
```

## 2. React Integration ⚛️

React developers typically interact with Vella using hooks and `fetch` (or React Query/SWR).

### Example 1: Standard Data Fetching
```tsx
import { useEffect, useState } from 'react';
import { User } from './vella-types';

export default function UserList() {
    const [users, setUsers] = useState<User[]>([]);

    useEffect(() => {
        fetch('http://localhost:8080/api/collections/users/records')
            .then(res => res.json())
            .then(data => setUsers(data.items));
    }, []);

    return (
        <ul>
            {users.map(u => <li key={u.id}>{u.email}</li>)}
        </ul>
    );
}
```

### Example 2: Real-Time WebSockets (React)
Listen to database changes instantly without polling.

```tsx
import { useEffect, useState } from 'react';

export default function LiveFeed() {
    const [messages, setMessages] = useState([]);

    useEffect(() => {
        const ws = new WebSocket('ws://localhost:8080/api/realtime');
        
        ws.onmessage = (event) => {
            const payload = JSON.parse(event.data);
            if (payload.action === 'INSERT' && payload.collection === 'messages') {
                setMessages(prev => [...prev, payload.record]);
            }
        };

        return () => ws.close();
    }, []);

    return <div>{messages.map(m => <p>{m.text}</p>)}</div>;
}
```

### Example 3: AI Chat Interface (Server-Sent Events)
Stream tokens directly from Vella's AI Gateway into a React state.

```tsx
async function streamAiResponse(prompt: string) {
    const response = await fetch('http://localhost:8080/api/ai/generate_stream', {
        method: 'POST',
        body: JSON.stringify({ prompt })
    });
    
    const reader = response.body.getReader();
    const decoder = new TextDecoder();
    
    while (true) {
        const { value, done } = await reader.read();
        if (done) break;
        const chunk = decoder.decode(value);
        console.log("New word from Claude/OpenAI:", chunk);
    }
}
```

## 3. Vue 3 Integration 🟩

Vue developers can easily wrap Vella's APIs into the Composition API or Pinia stores.

### Example 4: Vue Composition API
```vue
<script setup lang="ts">
import { ref, onMounted } from 'vue'
import type { User } from './vella-types'

const users = ref<User[]>([])

onMounted(async () => {
    const res = await fetch('http://localhost:8080/api/collections/users/records')
    const data = await res.json()
    users.value = data.items
})
</script>

<template>
  <ul>
    <li v-for="user in users" :key="user.id">{{ user.email }}</li>
  </ul>
</template>
```

### Example 5: Vue Watchers with Vella GIS
If you are building a map using Leaflet or Mapbox, you can watch Vella's spatial data.

```vue
<script setup lang="ts">
import { watch, ref } from 'vue'

const currentGps = ref<[number, number]>([0, 0])

watch(currentGps, async (newCoords) => {
    // Send a PostGIS Point to Vella
    await fetch('http://localhost:8080/api/collections/delivery/records', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
            location: newCoords // Vella automatically parses this into GiST indexed Points
        })
    })
})
</script>
```

## 4. Angular Integration 🅰️

Angular developers can wrap Vella's Real-Time Engine directly into **RxJS Observables**.

### Example 6: Vella WebSocket Service (RxJS)
```typescript
import { Injectable } from '@angular/core';
import { webSocket, WebSocketSubject } from 'rxjs/webSocket';
import { Observable } from 'rxjs';

@Injectable({ providedIn: 'root' })
export class VellaRealtimeService {
  private socket$: WebSocketSubject<any>;

  constructor() {
    this.socket$ = webSocket('ws://localhost:8080/api/realtime');
  }

  public getLiveUpdates(collection: string): Observable<any> {
    // Filter the RxJS stream for a specific Vella table
    return this.socket$.asObservable().pipe(
      filter(data => data.collection === collection)
    );
  }
}
```

### Example 7: Consuming in an Angular Component
```typescript
import { Component, OnInit } from '@angular/core';
import { VellaRealtimeService } from './vella.service';

@Component({
  selector: 'app-dashboard',
  template: `<div *ngFor="let alert of alerts">{{ alert.message }}</div>`
})
export class DashboardComponent implements OnInit {
  alerts: any[] = [];

  constructor(private vella: VellaRealtimeService) {}

  ngOnInit() {
    this.vella.getLiveUpdates('industrial_alarms').subscribe(data => {
      if (data.action === 'INSERT') {
        this.alerts.push(data.record);
      }
    });
  }
}
```

## 5. File Uploads & Multipart Forms

Vella supports standard multipart form data for uploading files, PDFs, or images (which can then be passed to the AI Gateway's Vision models).

### Example 8: React File Upload
```tsx
const uploadFile = async (file: File) => {
    const formData = new FormData();
    formData.append('document', file);
    
    // Upload to Vella's object storage
    await fetch('http://localhost:8080/api/collections/documents/records', {
        method: 'POST',
        body: formData
    });
}
```

## Summary
No matter which frontend framework you use, Vella behaves like a standard REST/WebSocket server, but with superpowers. You get strongly-typed data, instant real-time reactivity, native spatial GIS types, and a unified AI gateway, all without writing a single line of backend logic.
