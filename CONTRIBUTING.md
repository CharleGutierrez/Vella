# Contributing to Vella

First off, thank you for considering contributing to Vella! It's people like you that make Vella the God-Tier Decentralized Operating System it is.

## 🧠 The Vella Philosophy
Vella is designed to be the ultimate convergence of AI, Web3, HFT, and SCADA. We prioritize:
1. **Absolute Performance:** We write in memory-safe Rust. Zero-cost abstractions.
2. **Developer Experience (DX):** Agentic scaffolding and zero-config SDKs.
3. **Autonomy:** If a feature can self-optimize, let the AI Tuner do it.

## 🛠️ How to Contribute

### 1. Reporting Bugs
- Use the **Bug Report** issue template.
- Include OS, Rust version, and Vella version.
- Provide a minimal reproducible code snippet.

### 2. Suggesting Enhancements
- Use the **Feature Request** issue template.
- Explain *why* this enhancement aligns with Vella's God-Tier architecture.

### 3. Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes (`cargo test`).
4. Format your code with `cargo fmt`.
5. Run clippy to catch common mistakes (`cargo clippy`).
6. Update the documentation (in `README.md` or `/docs`).
7. Issue that pull request!

### 4. Development Setup
```bash
git clone https://github.com/CharleGutierrez/Vella.git
cd Vella
cargo build
cargo test
```
